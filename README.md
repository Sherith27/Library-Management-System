# Library-Management-System
Access the VUT Library system digitally.

VUT student can use a platform like Blackboard for example, to check availability and borrow books instead of going there to check only to search manually for books that are not even there.

Books available at VUT can be recorded, student can borrow or rather say make a borrow request on "Blackboard", if available then student can borrow and collect at campus. Borrow free books and also rent books.

I'm a student at VUT and I saw how easy it can be to still a book, to avoid that students make a request online and go to the library to collect only.
